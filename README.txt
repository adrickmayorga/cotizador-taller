SRNU CUSTOM - COTIZADOR CON HISTORIAL Y PDF

Archivos:
- cotizador.php             Cotizador principal; crea y edita cotizaciones.
- cotizaciones.php          Historial, búsqueda, edición, PDF y eliminación.
- generar_pdf.php           Generación/descarga de PDF con nombre automático.
- eliminar_cotizacion.php   Elimina una cotización.
- config/database.php       Conexión PDO a MySQL.
- srnu_cotizador.sql        Base de datos y tablas.
- pdf/                      Carpeta donde se guardan los PDF generados.
- CONFIGURACION.txt         Pasos de instalación.
